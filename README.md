# EduGuide AI

Complete frontend-only React/Vite prototype for the EduGuide AI academic and career support system.

Run: `npm install` then `npm run dev`.

Demo accounts:
- student@eduguide.ai / student123
- parent@eduguide.ai / parent123
- admin@eduguide.ai / admin123

All demo persistence uses localStorage. AI is a clearly labeled frontend simulation. Services are separated so a future Django REST API can replace the local implementations.
