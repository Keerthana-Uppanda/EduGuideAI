# EduGuide AI 🎓🤖

## AI-Powered Academic and Career Support System for First-Generation College Students and Their Parents

EduGuide AI is a student-support platform designed to bring academic and career guidance into one place. The system is aimed particularly at first-generation college students who may have limited access to family guidance about higher education, career opportunities, scholarships, deadlines, and skill development.

The platform also provides parent-oriented career information to help families understand different career paths and opportunities.

## 🚀 Key Features

- 👤 Student Profile and Dashboard
- 💼 Career Explorer
- 🗺️ Career Roadmaps
- 🎓 Scholarship Finder
- ⏰ Deadline Tracker
- 📚 Study Planner
- 📖 Learning Resources
- 🤖 Conversational Assistant Interface
- 👨‍👩‍👧 Parent Career Guidance
- 🔎 Rule-Based Matching
- 💾 Browser Local Storage

## 🏗️ System Architecture

EduGuide AI follows a modular four-layer architecture:

### 1. User Interface Layer
Handles React pages, dashboards, forms, navigation, and reusable UI components.

### 2. Application Service Layer
Manages profiles, careers, scholarships, deadlines, study goals, and related application workflows.

### 3. AI & Recommendation Layer
Provides the conversational-support interface and rule-based matching in the current prototype. This layer is designed for future AI and personalization integration.

### 4. Data Layer
The current prototype uses browser Local Storage for persistence, with scope for future database integration.

📌 Current Implementation

The current version is a functional frontend prototype implementing the major planned workflows. The prototype demonstrates the integration of career guidance, scholarship discovery, deadline tracking, study planning, learning resources, and parent-oriented career support.

The current implementation does not claim measured educational effectiveness. Future evaluation will involve user studies, verified information sources, and evaluation of recommendation performance.
